# ⚡ Zap 연습장 — Claude와 함께 배우는 Zapier 자동화 퀘스트

Zapier의 핵심 기능을 **하나씩 따라 하며 체험**하고, **Claude와 협업하는 방법**까지 익히는 인터랙티브 학습 사이트입니다. 실제 Zapier 계정 없이 안전하게 연습할 수 있는 시뮬레이터예요.

👉 **사이트 열기:** https://yalli2.github.io/zapier_practice/

## 구성 (21개 미션)

| 파트 | 미션 |
|---|---|
| 1부 · 시작하기 | Zapier와 Claude 첫 만남 · 첫 Zap(트리거→액션, 매핑, 테스트, Publish) · Task 계산과 Zap History |
| 2부 · 로직과 데이터 | Filter · Paths · Formatter · Schedule/Delay/Digest |
| 3부 · 개발자 도구 | Webhooks · Code by Zapier(+Claude가 쓴 코드) · Looping |
| 4부 · Zapier 플랫폼 | Tables · Interfaces · Chatbots · Canvas · Copilot |
| 5부 · Claude 협업 심화 | Zap 안의 AI 단계(AI by Zapier / Anthropic (Claude)) · Agents + 사람 승인 · Zapier MCP · Next Gen Zaps |
| 6부 · 운영과 실전 | Sub-Zap·Storage·Versions·Error handler · 최종 프로젝트(상담 자동화 시스템 + 수료증) |

## 특징
- 미션마다 **개념 → ✻ Claude 협업 팁(복사 가능한 프롬프트) → 단계별 실습**
- 앱/이벤트 고르기, 데이터 매핑, 조건 빌더, Formatter·코드 실행, 챗봇·MCP 채팅 시뮬레이터 등 손으로 하는 실습
- XP·레벨·배지, 진행 상황 자동 저장(브라우저)
- 프롬프트 도서관 · 용어 사전 · 요금·한도 메모(출처 링크 포함)

## 파일
```
index.html   화면 뼈대
style.css    디자인
js/data.js   미션·용어 데이터
js/labs.js   인터랙티브 실험실
js/app.js    진행·라우팅·도우미 엔진
```

> 학습용 시뮬레이터이며 Zapier 또는 Anthropic의 공식 사이트가 아닙니다. 메뉴·이벤트 이름과 요금 정보는 2026년 11월 기준 공식 문서를 참고했고, 바뀔 수 있습니다. 예시 데이터는 모두 가상입니다.
